# Feature Specification: 精听工坊（Intensive Listening Trainer）

**Feature Branch**: `001-intensive-listening-trainer`

**Created**: 2026-10-25

**Status**: Draft

**Input**: User description: "精听工坊 · 产品需求文档 v2.0（preview-862390.md）：面向语言学习者的单机精听训练工具——材料库总览、导入流水线（音频+官方文稿→结构解析→转写对齐→差异分析）、学习阶段（话轮排版、播放联动、生词/没听懂标记）、复习阶段（泛听+出题判分+掌握判定）、生词本卡片抽查、设置。2026-10-26 修订一：测验题型简化为整句听写；生词本升级为跨材料全局复习队列（简单间隔重复 + 首页到期入口；词/短语语境卡边听边看、没听懂句盲听卡）。修订二：复习条目不自动移除、由用户手动删除；学习阶段新增跟读功能（手动标记 + 大模型推荐，简单跟读交互，不录音不评分）。修订三：学习阶段文稿排版强制对齐 BBC 官方样式——按说话人分隔、标题加粗且含中文译名（若有）、该轮句子连成自然段、译文紧随对应英文段落弱化显示，同说话人的无标签续段渲染为同标题下的独立段落块。修订四：跟读推荐完全交由大模型（无本地规则，未配置时仅手动标记）；跟读单位扩展为任意文本片段（短语/单句/跨句多句均可）；跟读模式保持简单'播—停—模仿'，不做同步/脱稿档与语音要点提示。修订五（2026-10-28）：移除重点句机制与差异分析（导入仅保留转写+对齐出时间戳，不再判定重点句、不提供听音指引与不符告警）；「没听懂」改为句尾图标纯开关（无原因/备注）；学习界面新增「标记模式」开关——开启后禁用点击跳转，划词+填释义（可留空）加入生词本。"

## Clarifications

### Session 2026-10-27

- Q: 转写对齐完成后，仍无法分配到时间戳的官方句子（比如该句在音频中缺失或被识别漏掉）应该如何处理？ → A: 标记为"未对齐"：句子在文稿中正常显示并带"未对齐"标识，不参与测验抽题、不能被选为跟读播放起点或组成需播放的跟读片段，不支持单词级点击跳转；不估算、不编造时间戳。
- Q: 大模型生成跟读推荐片段的时机应该是什么？ → A: 手动触发：学习界面跟读面板提供「获取推荐」按钮，用户点击才调用大模型生成候选片段（可含多个句子），一键采纳或忽略；未配置大模型时不提供推荐入口，仅支持手动标记。
- Q: 一次复习会话应该练多少张到期的卡片？ → A: 每次上限 20 张：到期超过 20 张时一次最多练 20 张，练完或中途结束即收尾，剩余到期卡片次日继续到期、分天消化。
- Q: 设置页的大模型接入应该采用什么形态？ → A: 内置三家服务商预设：OpenAI / DeepSeek / 月之暗面 Kimi，均为 OpenAI 兼容接口；用户在设置中选择服务商并填写 API Key 与模型名，底层统一走 OpenAI 兼容协议。

### Session 2026-10-28

- Q: 去掉重点句的范围怎么定？ → A: 全部去掉：重点句判定、手动标记、听音指引（keyWords/asrText 对照）、测验抽题类别、卡片统计、差异分析与整体不符告警一并移除；导入只保留"转写 + 对齐出时间戳"。
- Q: 没听懂句标记是否保留"原因"？ → A: 纯开关：每个句子末尾提供「没听懂」图标，选中即标记、再点取消，不弹备注框、无原因/备注；盲听卡不再显示原因。
- Q: 添加生词/短语的交互如何设计？ → A: 学习界面提供「标记模式」开关：开启后禁用单词点击跳转，用户划选词/短语并输入释义（可留空）加入生词本；关闭后恢复点击单词跳转听音。

### Session 2026-11-03（导入流程改造）

- Q: 转写模型漂移严重，导入流程如何调整？ → A: 取消转写：官方文稿本来就是正确文本，导入改为 **wav2vec2 CTC 强制对齐**——把文稿字符序列直接钉到音频上（本机离线），产出官方词粒度的 start/end；不再依赖任何转写引擎（faster-whisper / Paraformer 退役），也不再需要 difflib 比对与 LLM 对齐精修。对齐模型可在设置页选择（base / large）。
- Q: 文稿与音频不匹配（粘错文稿）如何兜底？ → A: 质量守卫：对齐路径平均后验概率过低或音频装不下文稿时，按 FR-012 降级为"仅音频模式"，可重试对齐；绝不产出错误的高亮时间轴。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 导入材料并完成首次学习 (Priority: P1)

用户选择一段音频（播客、教材音频、考试听力材料），粘贴官方原文稿；系统解析出话轮结构（说话人、正文句、译文）并经用户确认后，用 wav2vec2 强制对齐把官方文稿逐词钉到音频上，生成带时间轴的学习材料。用户在学习界面跟随高亮播放，点击任意单词从该词开始听，反复回听难句，并在标记模式下划词添加生词/短语，用句尾图标标记"没听懂"的句子。

**Why this priority**: 这是产品的核心价值闭环——把"官方文稿 + 音频"转化为可交互的精听训练材料。没有它，复习检测、全局复习、跟读等后续功能都不存在数据基础。仅此一项即可交付完整可用的训练价值。

**Independent Test**: 导入一篇 BBC Learning English 风格的对话材料，用户可以在学习界面播放音频、看到当前句在话轮段落行内高亮、点击任意单词从该词开始播放、开关标记模式添加生词、用句尾图标标记没听懂句——全流程可独立完成并验证。

**Acceptance Scenarios**:

1. **Given** 用户已选择音频文件并填写标题，**When** 粘贴含说话人标签与中文译文的官方文稿，**Then** 系统将其解析为话轮结构并展示概览（识别出 N 个说话人、M 个话轮、K 条译文），用户可确认或返回修改原文稿
2. **Given** 用户确认解析结果，**When** 点击开始导入，**Then** 界面显示当前处理阶段（解析文稿 → 强制对齐）与进度，且用户可中途取消
3. **Given** 强制对齐完成，**Then** 每个官方句子获得起止时间与逐词时间戳；无法分配到时间戳的句子标记为"未对齐"
4. **Given** 材料已入库并进入学习阶段，**When** 用户打开学习界面，**Then** 文稿按官方样式渲染：按说话人分块，说话人名加粗小标题（含中文译名，若有），该轮句子连成一个自然段，译文紧随对应英文段落下方弱化显示
5. **Given** 材料已入库并进入学习阶段，**When** 用户播放音频，**Then** 当前句在行内高亮、视图自动滚动跟随；用户点击文稿中任意单词，音频从该词的时间点开始播放
6. **Given** 正在播放且自动跟随开启，**When** 用户手动上翻回看，**Then** 自动跟随立即暂停且页面不被拽回；点击"回到当前句"或任意句子后恢复跟随
7. **Given** 用户开启「标记模式」，**When** 划选一个词或短语并输入释义（可留空）确认，**Then** 该内容被持久标记（荧光笔底色）并汇入全局复习队列；标记模式下点击单词不再触发跳转；关闭标记模式后恢复点击跳转
8. **Given** 学习界面，**When** 用户点击某句末尾的「没听懂」图标，**Then** 该句显示视觉区分（红色虚线下划线）并汇入全局复习队列；再次点击取消标记并退出队列

### User Story 2 - 复习检测与掌握判定 (Priority: P2)

用户完成学习后进入复习阶段：文稿与译文全部隐藏、进度条只读，进行泛听；随时可开始检测，系统按优先级从未听懂句、含生词/短语的句子、随机句中抽句，用户听句子音频默写整句，判分后按 90% 达标线决定材料进入"已掌握"或回到学习/再测一次。

**Why this priority**: 检测是"学习→掌握"闭环的验收环节，验证的是耳朵的真实水平而非阅读能力。整句默写比填空、选择更严格：填空只考关键词，选择有 1/4 蒙对概率，整句默写要求句中每个词都听清、写出，才能真实反映听力水平。它是材料阶段流转与成绩记录的依据。

**Independent Test**: 对任一已入库材料，用户可进入复习、隐藏文稿泛听、完成一次整句听写测验、得到百分制得分与阶段流转结论——无需依赖学习界面之外的任何功能即可验证。

**Acceptance Scenarios**:

1. **Given** 材料处于学习阶段，**When** 用户点击"进入复习"，**Then** 全部文稿（含译文）隐藏，进度条只读（显示播放位置但不可拖动）
2. **Given** 材料处于复习阶段，**Then** 可用控制仅为播放/暂停与变速，且随时可点击「开始检测」（不强制听完整篇）
3. **Given** 用户开始检测，**Then** 系统按抽题优先级（没听懂句 > 含生词/短语的句子 > 随机句）抽取默认 10 句，句子不足则全部参与
4. **Given** 一题听写，**Then** 播放该句音频（可反复重听、可调速 0.5×~1.5×），用户默写完整句子后逐题提交
5. **Given** 用户完成全部听写，**Then** 系统按规范化文本精确匹配判分（忽略大小写、首尾空格、全部标点），每句计 1 个得分点，得分 = 默写正确句数 ÷ 总句数 × 100%
6. **Given** 得分 ≥90%，**Then** 材料进入「已掌握」，展示成绩与默写错误句子的回顾（用户输入与原文对照）
7. **Given** 得分 <90%，**Then** 展示默写错误的句子（用户可查看文稿），用户选择「回到学习」或「再测一次」
8. **Given** 任意阶段，**When** 用户手动回退重学，**Then** 阶段立即回退且数据保留；已掌握材料可随时查看文稿、重测，成绩照常记录

### User Story 3 - 跟读训练 (Priority: P3)

用户在学习界面选中任意想练的片段（可以是一个短语、一句话、连续多句）标记为「想跟读」，也可采纳大模型推荐的片段；进入跟读模式后逐条播放：片段播完自动停顿，用户模仿原音跟读，可重听、跳条、变速、循环。

**Why this priority**: 精听解决"听清"，跟读解决"说出口"。跟读的素材不局限于"难句"——训练说话能力靠的是语块、典型句型、语调样板的反复模仿，哪些片段值得练交给大模型判断，用户想练什么也可以自己选。软件只做简单有效的"播—停—模仿"，把跟读方法留给用户自己掌控。

**Independent Test**: 任一材料中，用户可手动标记任意片段（短语/单句/多句）或采纳大模型推荐，进入跟读模式完成一轮"播放—停顿—模仿—重听/跳条"，并管理跟读清单。

**Acceptance Scenarios**:

1. **Given** 学习界面，**When** 用户选中一段文本（短语、单句、跨句多句均可）标记为「想跟读」，**Then** 该片段在文稿上有视觉标记并进入跟读清单；取消标记即移出清单
2. **Given** 用户已配置大模型，**When** 用户在跟读面板点击「获取推荐」，**Then** 系统调用大模型生成若干值得跟读的片段候选（可含一个或多个句子）；用户可一键采纳或忽略，忽略的片段不再重复推荐
3. **Given** 用户未配置大模型，**Then** 系统不做跟读推荐，用户仍可手动标记任意片段，跟读功能不受影响
4. **Given** 用户进入跟读模式，**Then** 逐条播放跟读清单：每条片段播完自动停顿（由用户按键重听或跳下一条），可调整语速（0.5×~1.5×）、单条循环
5. **Given** 跟读清单为空，**When** 用户进入跟读，**Then** 系统提示先标记片段或采纳推荐

### User Story 4 - 材料库总览与管理 (Priority: P4)

用户打开应用即看到材料库：每张卡片呈现标题、时长、阶段状态、历史最好成绩、生词数、没听懂句数，据此决定今天学什么；当存在到期的复习条目时，首页显示"今日待复习 N 条"入口，一键进入全局复习；材料可重命名、可删除（连带音频与数据），页面提供新建导入、设置、生词本入口。

**Why this priority**: 材料库是训练进度的总览与日常入口，也是"回来复习"这一时机的承载点。它依赖前面故事产生的数据，但自身逻辑简单，可独立交付。

**Independent Test**: 无论是否有新导入，用户打开应用即可查看全部材料的进度卡片、经首页入口进入当日复习，并完成重命名、删除等管理操作。

**Acceptance Scenarios**:

1. **Given** 用户打开材料库，**Then** 每张卡片显示标题、时长、阶段状态（学习中/复习中/已掌握）、历史最好成绩、生词数、没听懂句数
2. **Given** 存在到期复习条目，**Then** 首页显示"今日待复习 N 条"入口，点击直达复习会话；无到期条目时不显示该入口
3. **Given** 用户重命名材料，**Then** 新标题立即生效并持久保存
4. **Given** 用户删除材料，**When** 确认删除，**Then** 音频、全部学习数据及其产生的复习条目一并删除
5. **Given** 用户在材料库页面，**Then** 可直接进入新建导入、设置、生词本

### User Story 5 - 全局复习队列与卡片复习 (Priority: P5)

练习材料产出的待补足项——不认识的单词、短语、没听懂的句子——自动汇入跨材料的全局复习队列，按简单间隔重复到期。材料库首页的"今日待复习"入口一键进入复习会话：词/短语卡带原句语境，展示原文边听边看；没听懂句卡盲听，纯音频验证是否听懂；自评结果决定下次复习时机；是否移除由用户手动决定。

**Why this priority**: 一篇材料练完，产出的是一批待补足的薄弱点：单词、短语、没听懂句。记单词的最终目的是"下次在语流里能听出来"——单词和短语必须带着使用场景（原句/对话）边听边看地复习，没听懂句最好的复习方式是盲听验证。这些数据产自每篇材料，但补足是全局的：间隔重复 + 首页到期入口给了用户"回来的时机"，让沉淀的薄弱点真正被消化，而不是躺在列表里等人想起。

**Independent Test**: 存在任一标记或没听懂句时，首页出现"今日待复习"入口，用户完成一轮混合复习（语境卡 + 盲听卡）后看到熟悉度与下次复习时机更新；无到期条目时入口不出现。

**Acceptance Scenarios**:

1. **Given** 用户在标记模式下添加生词/短语或点击句尾「没听懂」图标，**Then** 这些条目自动汇入全局复习队列，新条目 1 天后首次到期
2. **Given** 到期条目存在，**When** 用户从首页"今日待复习 N 条"进入复习会话，**Then** 会话按到期时间升序依次呈现到期的词/短语卡与没听懂句卡（单次最多 20 张，练完或中途结束即收尾，剩余次日继续到期）
3. **Given** 一张词/短语卡，**Then** 展示目标词（含用户填写的释义，若有）及其使用场景（所在原句/对话原文，目标词高亮），播放原声音频，用户边听边看；用户自评「认识 / 不认识」
4. **Given** 一张没听懂句卡，**Then** 默认盲听：仅播放原句音频（可反复重听、不限次数），不直接给文本；用户自评「听懂了 / 还是没听懂」
5. **Given** 用户对没听懂句自评"还是没听懂"，**Then** 可查看该句文稿后重听再判（次数不限）
6. **Given** 用户完成自评，**Then** 系统按简单间隔重复更新调度：通过则间隔按 1→3→7→15→30 天递增（30 天档后按 30 天周期循环），未通过则重置为 1 天后到期
7. **Given** 用户打开复习队列总览，**Then** 看到全部材料的三类条目汇总，支持按材料筛选、按类型筛选、按熟悉度排序、删除条目；条目不自动移除，是否删除由用户决定
8. **Given** 复习队列为空，**When** 用户尝试开始复习，**Then** 系统提示先在学习中标记生词或没听懂句

### User Story 6 - 设置 (Priority: P6)

用户在设置页选择 wav2vec2 对齐模型（base / large）并查看/预下载模型、配置大模型（可选，用于跟读片段推荐）、设置默认播放速度与译文默认显示偏好。

**Why this priority**: 设置是支撑性入口：默认配置开箱即用，设置页满足进阶配置与隐私可控的需求，但不阻塞核心流程。

**Independent Test**: 用户可在设置页完成全部配置项的查看与修改，修改后新配置对后续导入、学习与推荐生效。

**Acceptance Scenarios**:

1. **Given** 用户打开设置页，**Then** 可选择对齐模型（base / large）并查看模型下载状态、触发预下载
2. **Given** 对齐模型未下载，**When** 首次导入，**Then** 模型自动下载（走镜像源），下载失败明确提示并可重试
3. **Given** 用户配置大模型，**Then** 可启用/关闭跟读片段推荐；关闭或未配置时不做推荐，不影响其他功能
4. **Given** 用户在设置页修改默认播放速度或译文默认显示偏好，**Then** 新偏好对后续学习与导入生效

---

### Edge Cases

- **无说话人标签的材料**：全文视为单一说话人，按空行划分话轮（段落）
- **无法识别的行**：某行既不像标签也不像正文/译文时，按英文正文处理，保证不丢内容
- **句子数量不足**：不足以凑满默认题量时，全部句子参与测验
- **复习队列为空**：首页不显示"今日待复习"入口；用户尝试开始复习时提示先在学习中标记
- **来源材料被删除**：其产生的复习条目一并清除
- **没听懂句取消标记**：该句退出复习队列
- **对齐失败的句子**：仍无法分配到时间戳的官方句子标记为"未对齐"，在文稿中正常显示并带标识；不参与测验抽题，不可加入跟读清单，不支持单词级点击跳转
- **对齐中途取消**：材料不入库，不产生残留数据，用户可重新开始导入
- **对齐失败**（文稿与音频不匹配、模型异常、音频不可读）：材料降级入库为"仅音频模式"（仅播放可用，文稿交互禁用并提示），支持粘贴文稿重试对齐补齐数据
- **音频损坏或格式不支持**：导入时探测失败，提示"无法解码的音频文件，请更换文件"并拒绝导入，不产生残留数据
- **导入中关闭或刷新页面**：任务在服务端继续，重新打开应用后可重新进入导入进度页查看（轮询查询进度）
- **对齐模型未下载或下载失败**：设置页显示下载状态并可预下载/重试；导入时自动下载，网络不可用时对齐失败并按"仅音频模式"降级
- **材料无译文**：不显示「显示/隐藏译文」开关
- **大模型未配置或不可用**：不做跟读推荐，手动标记与跟读模式不受影响；「获取推荐」调用失败（超时/限流）时必须提示并可重试
- **存储文件损坏**：启动时检测到非法 JSON 时，将损坏文件备份为 `.corrupt` 后以空数据启动；某材料数据损坏时仅该材料标记为不可用，其余材料不受影响
- **用户忽略某条跟读推荐**：该片段不再重复出现在推荐中，仍可手动标记
- **跟读清单为空**：进入跟读时提示先标记片段或采纳推荐
- **已掌握材料重测低于 90%**：材料保持「已掌握」状态，成绩照常记录，用户可手动回退重学
- **练习中断**：关闭应用后重新打开，恢复到上次的音频位置与练习进度，全部标记与阶段状态不丢失
- **解析失败兜底**：任何解析异常不得导致内容丢失或导入流程崩溃

## Requirements *(mandatory)*

### Functional Requirements

**材料库**

- **FR-001**: 系统必须以卡片列表展示全部材料，每张卡片包含标题、时长、阶段状态（学习中/复习中/已掌握）、历史最好成绩、生词数、没听懂句数
- **FR-002**: 材料库页面必须提供新建导入、设置、生词本入口；存在到期复习条目时，必须在首页显示"今日待复习 N 条"入口，点击直达复习会话；无到期条目时不显示该入口
- **FR-003**: 用户必须能够删除材料（连带音频、全部学习数据及其产生的复习条目），删除前需经用户确认
- **FR-004**: 用户必须能够重命名材料，新标题立即生效并持久保存

**导入流水线**

- **FR-005**: 系统必须支持导入 mp3、wav、m4a、flac、ogg 格式音频，导入时要求填写标题
- **FR-006**: 系统必须支持粘贴或上传官方原文稿（纯文本，可含说话人标签与中文译文）
- **FR-007**: 系统必须把原文稿解析为话轮结构：单独成行的说话人标签（短文本，可带中文译名如 `Neil 尼尔`，可带冒号如 `Beth:`，兼容行内形式 `Beth: Hello...`）；英文正文按标点（`. ? ! ;`）切分为句子并归属当前说话人；中文字符占比过半的行判定为译文并挂到最近一个英文段落块（一个段落块可有多行译文，按原顺序拼接）；无标签材料全文视为单一说话人按空行划分话轮；既不像标签也不像正文/译文的行按英文正文兜底
- **FR-008**: 解析完成后系统必须展示结构概览（识别出的说话人数、话轮数、译文条数），经用户确认后才继续；用户可返回修改原文稿后重新解析
- **FR-009**: 对齐模型取设置页配置（base / large，默认 base）；导入流程不再选择引擎
- **FR-010**: 处理过程必须显示当前阶段与进度（解析文稿 → 强制对齐），并允许用户中途取消
- **FR-011**: 系统必须用 wav2vec2 CTC 强制对齐把官方文稿钉到音频上：以官方英文正文为已知文本做逐词对齐，为每个官方句子分配起止时间与**官方原词**逐词时间戳；标签行、译文行不参与对齐；文稿与音频不匹配（对齐置信度过低或音频装不下文稿）判定为对齐失败，绝不产出错误时间轴；仍无法分配到时间戳的句子标记为"未对齐"
- **FR-012**: 处理完成后材料必须入库并进入学习阶段；对齐失败（模型异常、网络不可达、文稿与音频不匹配、超时）时材料必须降级入库为"仅音频模式"：仅可播放音频（播放/暂停/变速/进度拖动），文稿交互（标记、测验、跟读）禁用并提示"对齐失败"；系统必须支持对该材料粘贴文稿重试对齐，成功后补齐文稿数据

**学习阶段**

- **FR-013**: 学习界面文稿排版必须对齐官方样式（以 BBC Learning English 文稿为准）：按话轮分隔，说话人名加粗作小标题（格式为英文名加可选中文译名，如 **Georgie 乔治**，无译名时仅英文名）；标题下该轮英文句子连成一个自然段；同说话人的无标签续段渲染为同一话轮下的独立段落块（保留原文空行分段，不重复标题）；无说话人标签的材料不显示小标题，只按段落分块
- **FR-014**: 中文译文必须紧随其所属的英文段落块下方显示，视觉上弱化（更小/灰色），同一话轮内各段落块保持"英文段 + 译文段"紧邻结构；必须提供全局「显示/隐藏译文」开关，材料无译文时不显示该开关
- **FR-015**: 播放时当前句必须在话轮段落的行内高亮（句子底色变化，不打乱段落结构）；必须提供可选的逐词高亮（卡拉OK式）界面开关
- **FR-016**: 播放时必须自动滚动跟随保持当前句在视野内；用户手动上翻回看时自动跟随必须立即暂停且绝不把页面拽回；点击"回到当前句"悬浮按钮或点击任意句子后恢复跟随
- **FR-017**: 用户点击文稿中任意单词，音频必须精确跳转到该词的时间点并从该词开始播放
- **FR-018**: 用户点击说话人标题旁的播放图标或句首标记，必须支持从该话轮/该句开始播放
- **FR-019**: 学习界面必须提供「标记模式」开关（默认关闭）：开启后禁用单词点击跳转，用户在文稿上选中词或短语后可输入释义（可留空）并加入生词本，已标记内容在文稿上必须有持久视觉标记（荧光笔底色）；关闭标记模式后恢复点击跳转；生词的取消通过在生词本总览中删除条目实现
- **FR-020**: 每个句子末尾必须提供「没听懂」图标开关：选中即标记该句没听懂（在文稿上有视觉区分，如红色虚线下划线）并汇入全局复习队列；未选中即为普通句；再次点击取消标记并退出复习队列；无需填写原因或备注
- **FR-021**: 播放控制必须包含：播放/暂停、变速（0.5× / 0.75× / 1.0× / 1.25× / 1.5×）、单句循环开关、重播当前句按钮、进度条拖动（仅学习阶段允许拖动）
- **FR-022**: 练习进度（音频位置、标记、阶段状态）必须实时持久化；中断后重新打开时恢复到上次的音频位置与练习进度

**跟读训练**

- **FR-023**: 用户必须能在学习界面选中任意文本片段（词、短语、单句、跨句多句均可）标记为「想跟读」；跟读片段在文稿上必须有视觉标记并可取消，取消后移出跟读清单；包含"未对齐"句子的片段不能加入跟读清单（无法定位音频）
- **FR-024**: 配置大模型后，系统必须支持跟读推荐：用户在跟读面板点击「获取推荐」时调用大模型，生成值得跟读的片段候选（不局限于单句，可含多个句子）；用户可一键采纳或忽略，忽略的片段不再重复推荐；未配置大模型时不提供推荐入口，仅支持手动标记，不影响跟读功能
- **FR-025**: 跟读模式必须支持逐条播放：每条片段播完自动停顿（由用户按键重听当前条或跳下一条），可变速（0.5× / 0.75× / 1.0× / 1.25× / 1.5×）、单条循环
- **FR-026**: 跟读清单必须汇总本篇全部跟读片段，支持在清单中跳转播放与移除

**复习阶段**

- **FR-027**: 进入复习阶段后必须隐藏全部文稿（含译文），进度条只读（显示播放位置但不可拖动）
- **FR-028**: 复习阶段可用控制仅限播放/暂停与变速；用户随时可点击「开始检测」进入测验（不强制听完整篇）
- **FR-029**: 测验默认 10 句/次，句子不足则全部参与；抽句优先级从高到低为：没听懂句 > 含生词或短语的句子 > 随机句；"未对齐"的句子不参与抽题
- **FR-030**: 测验题型为整句听写：每题播放该句音频（可反复重听、可调速 0.5×~1.5×），用户默写完整句子；测验内容仅来自英文正文句子（译文不参与出题）；测验题目在开始测验时生成并持久暂存，刷新或中断页面后已生成题目与已答内容必须保留，可继续作答
- **FR-031**: 判分必须按规范化文本精确匹配（忽略大小写、首尾空格、全部标点）；每句计 1 个得分点；得分 = 默写正确句数 ÷ 总句数 × 100%
- **FR-032**: 得分 ≥90% 时材料必须进入「已掌握」，展示成绩与默写错误句子的回顾（用户输入与原文对照）；得分 <90% 时必须展示默写错误的句子（此时可查看文稿），用户选择「回到学习」或「再测一次」
- **FR-033**: 阶段流转必须为 学习 →（点击"进入复习"）→ 复习 →（检测达标）→ 已掌握；任何阶段可手动回退重学；已掌握材料仍可随时查看文稿、重测，成绩照常记录

**全局复习队列**

- **FR-034**: 用户在标记模式下添加的生词/短语与点击「没听懂」图标标记的句子必须自动汇入跨材料的全局复习队列，作为三类复习条目（word / phrase / 没听懂句）
- **FR-035**: 材料库首页必须显示"今日待复习 N 条"入口（无到期条目时不显示），点击直达复习会话；单次会话最多呈现 20 张到期卡片；已自评卡片的调度结果即时生效并保留，未自评卡片保持到期状态；用户可随时退出并在任意时刻再次进入复习，退出不等于作废
- **FR-036**: 词/短语复习卡必须携带使用场景：展示目标词（含用户填写的释义，若有）及其所在的原句/对话原文（目标词高亮），可播放原声音频，用户边听边看后自评「认识 / 不认识」；自评"不认识"后必须显示该条目的释义（未填写释义时提示"未填写释义"并展示完整原句），自评"认识"直接进入下一张
- **FR-037**: 没听懂句复习卡必须默认盲听：仅播放原句音频（可反复重听、不限次数），不直接展示文本；用户自评「听懂了 / 还是没听懂」；自评"还是没听懂"时可查看该句文稿后重听再判（次数不限）
- **FR-038**: 复习调度必须采用简单间隔重复：新条目 1 天后首次到期；自评通过则间隔按 1 → 3 → 7 → 15 → 30 天递增，30 天档后按 30 天周期循环；自评未通过则重置为 1 天后到期
- **FR-039**: 复习队列总览必须汇总全部材料的三类条目，支持按材料筛选、按类型筛选、按熟悉度排序、删除条目；条目不自动移除，是否删除由用户手动决定；删除来源材料时其产生的复习条目必须一并清除
- **FR-040**: 复习队列为空时，用户尝试开始复习，系统必须提示先在学习中标记生词或没听懂句

**设置**

- **FR-041**: 设置必须提供 wav2vec2 对齐模型选择（base / large，默认 base），全部本机离线运行
- **FR-042**: 对齐模型必须支持下载状态展示与预下载；下载失败必须明确显示并可一键重试
- **FR-043**: 设置必须包含大模型配置（可选）：选择服务商（OpenAI / DeepSeek / 月之暗面 Kimi，均为 OpenAI 兼容接口），填写 API Key 与模型名，可启用/关闭跟读推荐；关闭或未配置时不做推荐、不影响其他功能
- **FR-044**: 设置必须包含默认播放速度与译文默认显示/隐藏配置

### Key Entities *(include if feature involves data)*

- **材料（Material）**：一篇听力练习材料。核心属性：标题、音频文件、时长、阶段状态（学习中/复习中/已掌握）、历史最好成绩、生词数、没听懂句数
- **话轮（Turn）**：材料中一段连续发言。归属一个说话人（可无），由若干段落块组成：每个段落块 = 一个英文自然段（下辖按标点切分的句子）+ 紧随其后的译文行（可有多行，按原顺序拼接）
- **句子（Sentence）**：官方原文的最小单位。核心属性：文本、所属话轮、对齐状态（已对齐 / 未对齐）、起止时间与逐词时间戳（仅已对齐句）、没听懂标记（布尔）
- **跟读片段（Shadowing Item）**：跟读练习单位。核心属性：文本（可跨句，可含多个句子）、来源（材料、起止词位置）、来源类型（手动标记 / 大模型推荐 / 已忽略）、音频起止时间（由起止词的逐词时间戳确定）
- **复习条目（Review Item）**：待补足的薄弱点，练习产出的全局复习资产。核心属性：类型（word / phrase / 没听懂句）、文本、释义（用户可选填，词/短语卡展示）、使用场景（来源句子与话轮，词/短语卡展示用）、熟悉度（known / reviews）、当前间隔天数与下次到期时间；不自动移除，由用户在总览中手动删除
- **测验（Quiz）**：一次复习检测记录。核心属性：抽中的句子列表、每句的用户默写输入、默写正确句数、总句数、得分（百分比）、日期
- **设置（Settings）**：用户偏好配置。核心属性：对齐模型（base / large）、大模型配置（可选：服务商 OpenAI / DeepSeek / Kimi、API Key、模型名）、默认播放速度、译文默认显示

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户完成导入向导的主动操作（选择音频、填写标题、粘贴文稿、确认解析、点击开始）在 3 分钟内、不超过 5 次提交动作（转写等待时间除外）
- **SC-002**: 对常见排版（以 BBC Learning English 为代表的说话人标签 + 译文排版）的抽样文稿，说话人标签行与译文行的解析识别准确率达到 95% 以上
- **SC-003**: 用户点击文稿中任意单词时，音频跳转位置与该词实际发音起始位置的时间偏差不超过 0.5 秒
- **SC-004**: 用户手动回看文稿时，页面被自动跟随拽回的发生率为 0；点击"回到当前句"后自动跟随 100% 恢复
- **SC-005**: 复习检测模式下，文稿、译文与进度拖动对用户的可访问性为 0（约束满足率 100%），确保检测反映真实听力水平
- **SC-006**: 同一材料连续两次检测的得分差异不超过 15 个百分点（检测稳定性）；达标线统一为 90%
- **SC-007**: 词/短语复习卡 100% 携带原句语境（原文 + 原声，目标词高亮）；没听懂句卡默认盲听（作答前不展示文本）的实现符合率为 100%
- **SC-008**: 未配置大模型时，手动标记任意片段与跟读模式 100% 可用；跟读推荐 100% 来自大模型（无本地规则推荐）
- **SC-009**: 到期复习条目在材料库首页 100% 可见，从打开应用到进入复习会话不超过 2 次点击
- **SC-010**: 间隔重复策略生效：自评通过的条目下次到期时间按计划递增（1→3→7→15→30 天后循环），未通过条目 1 天内重现
- **SC-011**: 练习中断后重新打开，100% 恢复上次音频位置、全部标记与阶段进度
- **SC-012**: 学习界面文稿排版与官方样式抽样比对（按说话人分块、加粗标题含中文译名、句连成自然段、译文紧随对应英文段落弱化显示、同说话人无标签续段不重复标题）符合率 100%

## Assumptions

- 目标用户为语言学习者（以英语材料为主），单机个人使用；数据不出本机：强制对齐完全本地离线运行，大模型为可选能力且可关闭，关闭后核心功能不受影响（符合项目宪法"本地优先"原则）
- 首次使用零必填配置即可开始导入：对齐模型首次使用时自动从镜像源下载（符合"开箱即用"原则）
- 90% 掌握线为需求文档给定的经验值，后续版本可根据用户反馈调整
- 测验题型为整句听写（2026-10-26 修订，替代 v2.0 文档中的听句填空 + 听句选文）：抽句类别"含生词/连读"实现为"含生词或短语的句子"
- 测验逐句作答、逐题提交（提交后不可修改），全部完成后统一判分并逐句展示用户输入与原文对照
- 判分归一化边界口径（2026-10-28 补充，后续可优化）：忽略全部标点（含句中）、全角字符转半角后比较、缩写不展开（`I'm` 须写作 `I'm`，`I am` 判错）
- 复习间隔序列 1 → 3 → 7 → 15 → 30 天为默认经验值，到达 30 天档后按 30 天周期循环；条目不自动毕业或移除，是否删除完全由用户决定
- 词/短语卡的"使用场景"默认取目标词所在的官方原句及所属话轮上下文，目标词在文本中高亮
- 「生词本」为用户可见的产品名称：材料库入口与操作条均指跨材料的全局复习队列（复习条目的总览管理）
- 界面开关（译文显示、逐词高亮、标记模式）不持久化：每次进入学习界面时，译文开关取设置页默认偏好，逐词高亮与标记模式默认关闭
- 复习会话内卡片按到期时间升序混合呈现（不分组）；盲听卡不限重听与再判次数；跟读模式每条播完停顿，由用户按键推进（重听/下一条）
- 跟读 v1 为简单跟读：不录音、不评分、不提供同步/脱稿档与语音要点提示（后续版本再评估）；同步跟读等进阶方法由用户自行掌控
- 跟读推荐完全由大模型负责（仅使用文稿文本，不上传音频文件）；未配置大模型时不做推荐，也不提供本地规则推荐
- 已掌握材料重测得分低于 90% 时，材料保持「已掌握」状态且成绩照常记录，用户可手动回退重学
- 应用在本机浏览器中打开即用，不提供多设备同步（超出单机定位，符合"简洁与单一职责"原则）
- 单词级精确跳转与跟读片段的音频起止均依赖 wav2vec2 强制对齐产出的**官方原词**逐词时间戳；对齐仅使用英文正文，标签行与译文行不参与
