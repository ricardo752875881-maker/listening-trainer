# Quickstart: 精听工坊验证指南

**目的**: 以最少的操作走通"导入 → 学习 → 测验 → 复习队列 → 跟读"全链路，验证功能符合 [spec.md](../spec.md)。

**前置**: Windows / Python 3.11+ / 现代浏览器（Edge/Chrome）。

## 启动

```bash
python -m venv .venv && .venv\Scripts\activate   # Git Bash: source .venv/Scripts/activate
pip install -r backend/requirements.txt
cd frontend && npm install && npm run build && cd ..   # 前端构建（Node 20+；发布版已含 dist 可跳过）
uvicorn backend.app.main:app --port 8000
# 浏览器打开 http://localhost:8000
```

前端开发模式（可选）：`cd frontend && npm run dev`（Vite 代理 API 至 8000 端口）。

预期：材料库页面（空态）+ 新建导入/设置/生词本入口。

## 场景 1：导入（P1 流水线）

1. 准备任意 mp3 + 一份 BBC 风格文稿（含 `Georgie 乔治` 式说话人标签与中文译文）
2. 导入向导：选音频 → 填标题 → 粘贴文稿 → 查看结构预览（说话人/话轮/译文计数）→ 确认 → 开始
3. 观察阶段进度（转写 → 对齐 → 分析）可取消；small 模型约音频时长 1/8 的等待
4. 预期：入库后进入学习界面，文稿按官方样式渲染（说话人加粗标题、句连成段、译文紧随弱化）；无法对齐的句子带"未对齐"标识

## 场景 2：学习联动（P1）

- 播放：当前句行内高亮、自动滚动跟随；手动上翻后跟随暂停，点"回到当前句"恢复
- 点击任意单词 → 音频从该词开始播放
- 开启「标记模式」→ 划选一个词 → 输入释义（可留空）→ 加入生词本（荧光笔底色）；关闭后恢复点击跳转
- 点击句尾「没听懂」图标 → 该句红色虚线标记；再点取消
- 关闭浏览器重开 → 播放位置与全部标记恢复

## 场景 3：测验与掌握（P2）

1. 学习阶段点"进入复习" → 文稿/译文隐藏、进度条只读
2. 点「开始检测」→ 默认 10 句整句听写（可反复重听、可调速）
3. 逐句默写提交 → 统一判分展示"我的输入 vs 原文"（默写错误句可查看文稿）
4. 预期：≥90 分材料变「已掌握」并展示错题回顾；<90 可回学习或再测

## 场景 4：全局复习队列（P5）

1. 材料库首页出现"今日待复习 N 条"（新条目 1 天后到期；测试可将系统日期调至次日，或直接操作 `data/review-queue.json` 中 dueAt 字段为今天——数据为可读 JSON，改后重启服务即可）
2. 进入复习会话：词/短语卡带原句语境（含你填的释义）边听边看，自评认识/不认识；没听懂句卡盲听，自评听懂/没懂，可查看文稿后重听再判
3. 预期：自评后卡片不再出现（通过升档/未通过 1 天后重现）；首页入口 ≤2 次点击可达；一次会话最多 20 张

## 场景 5：跟读（P3）

1. 学习界面选中任意片段（短语/单句/多句）→ 标记「想跟读」
2. 设置页配置大模型（DeepSeek 为例：provider + apiKey + model）→ 跟读面板点「获取推荐」→ 采纳或忽略候选
3. 进入跟读模式：逐条播放-停顿-模仿，可重听/跳条/变速/单条循环
4. 预期：未配置大模型时无推荐入口、手动标记不受任何影响；范围含未对齐句的片段被拒绝（409）

## 冒烟（宪法 Development Workflow）

任何变更后走通最小路径：加载音频 → 播放 → 单句循环 → 变速 → 标记生词 → 记录进度，然后：

```bash
cd backend && pytest -q          # 核心逻辑单测：解析/对齐/判分/调度/抽题
```
